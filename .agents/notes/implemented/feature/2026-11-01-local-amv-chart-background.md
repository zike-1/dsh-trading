# Agent Note: 本地 0AMV 原生主图背景区间

Status: implemented

## Problem

既有技术指标机制消费价格序列，无法表达本地活跃市值多空背景。旧提取记录没有可复用的 VDAT 解码器；以旧 Excel 冒充最新状态或无限前向填充都会错误标记当前行情。

## Decision

- 预置 amv-regime 以“活跃市值多空区间”注册，使用现有 chart activation、适用范围和持久化机制。默认关闭，只适用于 cn 日 K；代码守卫使用户手改级别也不能在周/月/分钟线误渲染。
- definition 的可选 renderMode=background 声明该类输出为空；存量指标仍走原有价格序列契约。TvChart 把 primitive 附着到蜡烛主 pane，底层绘制红/浅绿透明背景，不参与价格轴范围、不创建副图、不改策略或交易链路。
- primitive 每次重绘读取整数柱中心坐标，由相邻中心间距推算半柱边界；当前图表库对半整数下标返回零，真实画布门禁覆盖这一失效模式。图表自行处理缩放、平移、分隔 pane 和 resize。只匹配真实源日期，数据缺失和末日以后留白。区间窄时只画多/空字，完整区间日期在十字线读数状态栏显示。
- 多空计算从完整历史起点顺序推进：单日 >=4% 或相邻两日算术合计 >=4% 转多；当日 <=-2.3% 优先转空；其余延续。没有首个信号前未知，独立交易日历发现缺日或遇非法值后清空旧状态与两日上下文，等待新信号。
- /amv-regime 走现有已认证桥前缀，服务端只读本地文件，不接受请求传入路径；失效返回 available=false 与原因，客户端清空背景，不回退旧 Excel、旧缓存或其它行情源。开启时每分钟读取，关闭停止，换股票/周期丢弃旧 effect 响应。
- 数据布局、实际文件、历史对账与日历覆盖的唯一说明位于仓库根“通达信本地数据文件说明与使用指南.md”第 6.3 节。本地环境变量 DSH_TRADING_AMV_FILE、DSH_TRADING_AMV_CALENDAR_FILE 可覆盖当前 Windows 缺省路径；其它机器缺文件时明确不可用。

## Alternatives considered

- 复用旧解码脚本：针对性检索现有指南、outputs、项目源码后未找到可执行解码器，现有材料也明确记录缺失。当前解析器通过完整 Excel 数值与状态对账和二进制索引交叉校验建立证据，不重复已有可用工具。
- 把日频 aux 的前向填充直接用于区间：该机制允许取先前最近值，会越过本指标缺口和末日，故采用精确日期匹配。
- 用价格 area/histogram 模拟背景：会污染主图价格轴或增加无意义序列，改用原生 pane primitive。
- 周/月 K 聚合：单根可能跨多个相反状态，首版不在没有可靠映射时宣称支持。

## Consequences

新增数据读取、纯计算与原生绘制模块，无新业务依赖。已有指标的数学计算和交易功能保持原路径。数据只在本机读取，不写入包或分发数据。收盘日状态是当日收盘后描述，不是当日开盘可交易信号；历史区间终点属于复盘信息。

构建、测试、桌面验收及其限制随当前工作区交付报告记录在 docs/amv-native-chart-verification.md，未完成的 GUI 验收不计为通过。

## 组件回归入口

`pnpm ui:check --amv-chart` 只构建真实 TvChart 组件夹具，读取实际本地 0AMV 并运行无窗口 Chrome 画布断言；它不启动 DSH 宿主、桌面壳或 Computer Use。夹具不进入产品包，不代表完整终端界面或部署验收。自动断言覆盖两色实际绘制、整数坐标兼容、缩放/拖动重绘、范围切换、持久化和关闭清除。测试进程按树回收。

## 实际终端刷新与验证

实际部署还包含 client-ui-indicators 的前端构建：它把预置名册内嵌进 client.js，只更新纯指标库不会使既有选择器出现新条目。用户已批准按桌面脚本对应的原入口更新 trading-web；四个旧库先备份，更新前后校验指纹，宿主本体与其他 profile 不变。具体运行目录、恢复位置和 10 项实际终端交互结果归 docs/amv-native-chart-verification.md。

`ui:check --url <本地认证入口> --amv-live` 检查已运行终端，不创建替代宿主、不发送会话或交易；认证值只从本地忽略的 .env 在内存传入。Windows 按测试 Chrome 的 PID 回收进程树，等待 close 后异步清理专用目录，避免同步删除阻塞退出回调导致 EPERM。
